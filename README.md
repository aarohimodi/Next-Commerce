## Next Commerce

Next Commerce is a full-stack e-commerce web application built using Next.js. It allows users to browse products, manage their cart and wishlist, and place orders. It also includes an admin panel to manage the store.

## Features

- User registration and login
- Product and category management
- Product search, filtering, sorting, and pagination
- Shopping cart and wishlist
- Order placement and order management
- Admin dashboard
- Image uploads using Cloudinary
- Protected routes and role-based access

## Tech Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Next.js API Routes
- Database: MongoDB, Mongoose
- Authentication: JWT, bcrypt
- State Management: Redux Toolkit
- Forms: React Hook Form
- Image Storage: Cloudinary
